# 🏥 MedDhatri AI — Frontend Web App

Production React 18, Vite, and Tailwind CSS Frontend Application for MedDhatri AI.

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server (Port 5173):
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
